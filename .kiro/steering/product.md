# Stacks: Product Vision

A browser revival of Apple HyperCard—visual programming for everyone, brought to the web.

## Core Experience

- **1-bit Classic Mac Aesthetic**: Black, white, gray only. System 7 era UI. CRT monitor feel. Nostalgic but functional.
- **Stacks of Cards**: Drag, navigate, and interact with card-based information. Each card is a self-contained unit with buttons, fields, and visual layout.
- **Scriptable Interactivity**: HyperTalk-style scripting on buttons and fields. Write logic in plain English-like syntax.
- **AI-Assisted Script Writing**: Describe what you want in English; AI generates human-readable, editable HyperTalk code. No black-box magic—every line can be understood and modified.
- **Shareable Stacks**: Publish stacks as links. Hosted on Cloudflare Pages/Workers for instant, global distribution. No login required to view.

## Target User

Non-programmers and hobbyists who want to build interactive experiences without leaving the browser. Teachers, artists, tinkerers revisiting HyperCard's magic.

## Out of Scope (for Kiroween)

- Networking from scripts (sandboxed execution only).
- Complex multimedia (focus on text, simple graphics).
- Multi-user collaboration.
- Mobile-first design (desktop-optimized).

## Success Metrics

- Stack creation and sharing works end-to-end.
- AI script generation produces editable, functional code >80% of the time.
- Stacks render consistently across browsers.
